# PPMD 10-Year Anniversary Site — Content Template

Fill in the fields below and hand this file back — every visible text on the site
is listed here, section by section. The text currently on the site is shown as
`(current: …)` so you always know which field you are replacing.

**How to use this file**

- Replace each `> …` line with your final text.
- Blocks marked **REPEATABLE** can be duplicated as many times as needed
  (or deleted) — the site adapts to the number of entries.
- Numbers shown as `auto` are calculated by the site (e.g. people counts) —
  no content needed.
- Keep the tone premium, warm and editorial. Short beats long everywhere.
